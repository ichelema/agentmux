# Indice della memoria

Memoria persistente del progetto AgentMux: i fatti durevoli che servono a più sessioni. Ogni file
tratta un solo tema. Leggi questo indice, poi apri solo i file che servono al lavoro.

| File | Contenuto |
|---|---|
| [storico.md](storico.md) | Issue chiuse: PR, merge, review, esito |
| [decisioni.md](decisioni.md) | Decisioni dell'utente, con data e motivo |
| [insidie.md](insidie.md) | Problemi già incontrati: causa e correzione |
| [punti-aperti.md](punti-aperti.md) | Deviazioni, rischi rinviati e note in attesa di una decisione |
| [ambiente.md](ambiente.md) | Linear, GitHub, Hindsight, path, comandi, copie seed |

## Regole

- La memoria è un consiglio, non una fonte di verità: controlla ogni fatto su Git, Linear e
  `docs/` prima di usarlo.
- Scrivi solo fatti controllati e durevoli, in italiano.
- Aggiorna il file del tema e non creare duplicati. Per un tema nuovo crea un file e aggiungi una
  riga alla tabella.
- Quando un fatto cambia, correggi la riga: la storia resta in Git.
- Non scrivere qui lo stato della issue attiva (va nel checkpoint su Linear), il prossimo passo (va
  in `handoff.md`), segreti o conversazioni.
- Per il commit segui «Chiusura della sessione» in [`CLAUDE.md`](../CLAUDE.md).
